FLORENCIO — VIDEO DE FONDO

Esta carpeta queda reservada para el fondo animado de /florencio.

Archivo recomendado:
florencio-background.mp4

Ruta pública:
/video/florencio-section/florencio-background.mp4

Recomendaciones:
- 5–12 segundos, pensado para loop.
- Sin audio.
- Movimiento muy sutil (partículas, luz, ondas, respiración, etc.).
- Mantener zonas oscuras/limpias donde irán los textos.
- No necesita transparencia.

Desde Admin → Florencio se puede cambiar la URL del fondo si quieres usar otro archivo.
